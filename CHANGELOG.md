# Changelog

## 2.0.0
- **Selective sync**: pick Drive folders from a tree (or sync all of My Drive).
- **Easier sign-in**: one-click "Sign in with Google", "Sign in using a link", sign out.
  `credentials.json` is now optional (Advanced menu).
- **Synced files tab**: tree view of everything synced; copy or export as text tree (`.txt`) or CSV.
- **Windows support** (installer + portable ZIP) and **RPM** package, alongside DEB.
- Safer downloads (temp file + atomic rename), Windows-safe file names, Stop button.

## 1.0.0
- First release: two-way sync, light/dark theme, tray icon, DEB package.
