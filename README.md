# DriveSync by Iqbal
Google Drive sync client for Linux (PyQt5) with light/dark themes.

## Install
Download the .deb from the Releases page, then:
    sudo apt install ./drivesync-iqbal_1.0.0_all.deb

## Setup
Create an OAuth "Desktop app" client in Google Cloud Console (Drive API enabled),
then use "Import credentials.json" inside the app.

## Build from source
    ./build_deb.sh
